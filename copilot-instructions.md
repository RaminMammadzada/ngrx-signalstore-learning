# NgRx SignalStore Learning Project

This project is designed to help learn NgRx SignalStore, Angular's new signal-based state management solution.

## Project Focus
- Learn NgRx SignalStore fundamentals
- Understand signal-based state management
- Practice with real-world examples
- Compare with traditional NgRx patterns

## Key Learning Areas
1. **Basic SignalStore Setup** - Creating and configuring stores
2. **State Management** - Reading and updating state with signals
3. **Computed Values** - Derived state using computed signals
4. **Effects** - Handling side effects and async operations
5. **Custom Features** - Building reusable store features
6. **Integration Patterns** - Using SignalStore with components and services

## Development Guidelines
- Use Angular 19+ with standalone components
- Leverage signals throughout the application
- Follow NgRx SignalStore best practices
- Include comprehensive examples and documentation
